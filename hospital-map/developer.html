Поправка на население

Численность населения взята из сообщения пользователя. Город и район не складываются. Связь организации с территорией предложена по названию и может быть изменена в её карточке. Дата населения и сопоставимость границ не подтверждены. Числитель относится к взрослым прикреплённым, знаменатель — ко всему населению; это не процент охвата взрослых.

Повторяющееся значение 67 754 для разных районов сохранено как предоставлено и требует проверки. Значения населения можно исправить в карточке организации. Изменения сохраняются на этом устройстве и экспортируются в JSON.

Адреса и география

Документ содержит закрепление адресов за организациями и филиалами. Привязки к номерным терапевтическим участкам нет. По найденным улицам и населённым пунктам строятся полупрозрачные векторные зоны с пунктирной границей. Перекрывающиеся оболочки разделяются ячейками ближайших закреплённых адресных ориентиров (Вороного). Внутренние области зон не пересекаются. Между контурами оставлен служебный зазор менее метра. Совпадающие координаты разных больниц не задают принадлежность домов: неоднозначные фрагменты остаются неокрашенными. Доля найденных адресов указана в карточке. Адресные точки можно включить отдельно; точные границы и список домов контур не заменяет.

Положения всех 38 организаций заданы координатами из файла пользователя. Эти точки используются для маркеров больниц и конечных точек маршрутов без геокодера. Адрес объекта показан в карточке; совпадающие точки отмечены отдельно. Старые результаты поиска и прежние ручные координаты заменены данными файла. Новую ручную поправку можно сохранить в карточке или вернуть координаты из файла. Точные границы можно загрузить в формате GeoJSON, указав organizationId.

Мощность и периоды

Форма 30, таблица 1010 показывает плановые посещения в смену по амбулаторным подразделениям на 01.01.2026, включая разные профили. В обобщённой симуляции плановые посещения в смену приняты как пропускная способность больницы по всем профилям. Число смен и спрос за сопоставимый период пока не заданы, поэтому загрузка и свободные места ещё не рассчитываются. Текущие цвета карты отражают численность прикреплённых или время пути.

Замечания к данным

    Локальные настройки

    Исправления населения, привязки территорий и введённые вами координаты хранятся в браузере. Исходные файлы не изменяются. Найденные адреса, положения больниц и результаты проверки автоматически сохраняются в IndexedDB. Готовые векторные контуры также сохраняются в IndexedDB и восстанавливаются без повторного построения. При изменении адресов границы пересчитываются локально. Хранилище привязано к браузеру и адресу сайта, включая порт. Для переноса или резервного копирования скачайте адреса и зоны. Ключи API в резервную копию не входят.

    Яндекс Карты

    Ключ нужен только для подложки Яндекс Карт. Время пути рассчитывается локально, без ключей маршрутизатора и геокодера.

    Как получить ключ и открыть страницу
    1. Войдите в кабинет разработчика Яндекс Карт.
    2. Подключите JavaScript API и скопируйте ключ.
    3. Дождитесь активации (обычно до 15 минут).
    4. В ограничении по HTTP Referer укажите только localhost, без протокола и порта. Поле IP-адресов оставьте пустым. Сохраните изменения и подождите до 15 минут.

    Для запуска через localhost откройте start-localhost.cmd и используйте http://localhost:8765/. При открытии index.html двойным щелчком заголовок HTTP Referer отсутствует. Доменное ограничение ключа может блокировать запросы. Сайт не содержит серверной части; запуск через HTTP зависит от требований ключа.

    Если карта появилась, но адресный поиск отклонён, проверьте доступ к геокодированию и ограничения ключа в кабинете. Появление одной подложки не подтверждает работоспособность ключа.

    Резервные копии проекта

    Один JSON переносит найденные и неподтверждённые адреса, готовые контуры, маршруты, координаты и настройки расчёта. Ключи API не включаются.

    Содержимое выбранной копии

    Перед восстановлением текущая версия автоматически сохраняется в браузере. Её можно скачать кнопкой выше. Объединение сохраняет найденные адреса и более свежие маршруты. Полное восстановление возвращает данные и настройки выбранной копии.
