# Карта больниц Тульской области

Готовая локальная версия: время пути на машине и пешком, зоны прикрепления и нагруженность больниц.

## Открыть карту

1. Скачайте архив **tula-hospital-map-v1.0.0.zip** из раздела **Releases**. Также подходит **Code → Download ZIP**.
2. Полностью распакуйте архив в любую папку Windows 10 или 11.
3. Дважды нажмите **START.cmd** в корне папки.

Скрипт сам запустит localhost и откроет пользовательскую карту в браузере. Python, Node.js, Docker, права администратора, ввод ключа и импорт файлов для просмотра не нужны. Используются штатные Windows PowerShell 5.1 и .NET Framework. Для загрузки подложки Яндекс Карт требуется интернет; готовые расчёты находятся внутри проекта.

Окно запуска оставьте открытым, пока работаете с картой. Для остановки нажмите Ctrl+C или закройте это окно. Если порт 8765 занят, скрипт выберет свободный из следующих 31 портов. Повторный запуск этой же папки переиспользует её сервер и снова открывает браузер.

## Что уже включено

- 38 больниц и полное покрытие области.
- Завершённый расчёт сетки 5 км: 1 942 ячейки, 3 884 ответа для двух способов передвижения. Ячейки без найденного пути заполнены по соседним измеренным ячейкам своей больницы.
- Переключение длительности пути, зон прикрепления и нагруженности. Прикреплений на 1 000 жителей: меньше 700 — зелёный, 700–1 000 включительно — жёлтый, больше 1 000 — красный, нет данных — серый.
- Встроенный публичный ключ Яндекс JavaScript API. Для запуска на localhost менять его не требуется; работоспособность подложки зависит от доступности Яндекса, активности, ограничений и квоты ключа.
- Карточки и таблица: название, прикрепление на 1 000 жителей, площадь зоны и плановая пропускная способность.

Браузерная память не требуется для первого просмотра: все исходные для него значения загружаются из `hospital-map/viewer-data.js`. Новые локальные расчёты и выбранные режимы затем запоминаются в отдельном хранилище пользователя.
